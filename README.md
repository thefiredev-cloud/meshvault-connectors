# Retired: hosted MCP gateway

> **This hosted gateway is retired (2026-10-06).** The service that ran at `thefiredev.com/mcp` is shut down, its OAuth endpoints are gone and the registry listing is deprecated.
>
> Protocol Guide and JudgeFinder now host their own MCP servers, operated by The Fire Dev LLC:
>
> - **Protocol Guide MCP:** https://protocol-guide.com/api/mcp (EMS protocol search, [protocol-guide.com](https://protocol-guide.com))
> - **JudgeFinder MCP:** https://judgefinder.vercel.app/api/mcp (judge and court lookup, [judgefinder.vercel.app](https://judgefinder.vercel.app))
>
> Add those URLs to your MCP client instead. Listing: https://thefiredev.com/mcp-servers. Questions: tanner@meshvault.ai.

## What is left here

This repository is archived, read-only source for the retired gateway: a Hono service on Vercel that fronted EMS and legal tools with OAuth 2.1, API keys and Stripe billing. It is kept for reference under the MIT license. It is not a maintained product, and the hosted plans, free keys and Pro subscriptions no longer exist. Data from third-party sources keeps its own terms; see each source.
