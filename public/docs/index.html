Docs

MeshVault Connectors is one remote MCP server (Streamable HTTP, stateless JSON responses) exposing 18 read-only tools in four groups. Protocol version 2025-06-18 and later clients work.

Endpoints

/mcpMain endpoint. Requires OAuth or an API key.
/mcp/tryNo key. 10 calls a day per network. For quick trials and reviews.
/.well-known/oauth-protected-resourceOAuth discovery (RFC 9728). Authorization server metadata at /.well-known/oauth-authorization-server.
/api/usageYour plan, daily limit and calls used today (Bearer key).

Authentication

OAuth 2.1 with dynamic client registration, authorization code and PKCE (S256 only). The sign-in page asks for your API key or creates a free one. Access tokens last one hour; refresh tokens rotate and a replayed token revokes the session.

API key: send Authorization: Bearer mvc_… (or X-API-Key). Keys are stored only as SHA-256 hashes. Revoked keys stop working within about 10 seconds.

Quotas

Anonymous10 tool calls a day per network, /mcp/try only.
Free key100 tool calls a day.
Pro, $19 a month5,000 tool calls a day.

Only tools/call counts. Listing tools is free. When the limit is reached the tool returns an error naming the plan, usage and reset time (00:00 UTC). Calls rejected for bad input, and calls that fail because a data source was unavailable, are given back.

Billing

Subscribe on the pricing section. Payment is on Stripe Checkout. Paste an existing free key to upgrade that key, or leave it blank and a Pro key is issued on the confirmation page (shown for 24 hours). Cancelling ends Pro: upgraded free keys drop back to Free, keys issued by the purchase are revoked at the end of the paid period.

Safety and sources

EMS results come from Protocol Guide and are for education and reference only; they are not medical direction. Legal results come from JudgeFinder and are informational, not legal advice. Health results come from CMS NPPES and FDA openFDA; they are unvalidated public data and not medical advice. Model sizing results are estimates. Every tool response repeats the relevant notice.
