Connect it

Server URL: /mcp. Clients that support OAuth (Claude, ChatGPT) walk you through sign-in, where you paste a key or create a free one in one step. Command-line clients send the key as a Bearer token.

Settings, Connectors, Add custom connector. Paste the URL below. Claude opens the sign-in page; paste your key or create a free one.

__ORIGIN__/mcp

Settings, Connectors, Advanced, turn on Developer mode, then Create. Choose MCP server, paste the URL, set authentication to OAuth.

__ORIGIN__/mcp

Add to ~/.gemini/settings.json:

{
  "mcpServers": {
    "meshvault": {
      "httpUrl": "__ORIGIN__/mcp",
      "headers": { "Authorization": "Bearer $MESHVAULT_API_KEY" }
    }
  }
}
claude mcp add --transport http meshvault __ORIGIN__/mcp \
  --header "Authorization: Bearer $MESHVAULT_API_KEY"

Add to ~/.codex/config.toml:

[mcp_servers.meshvault]
url = "__ORIGIN__/mcp"
bearer_token_env_var = "MESHVAULT_API_KEY"

Want to try before you sign up? /mcp/try needs no key and allows 10 calls a day per network.

Questions

What is an MCP connector?

MCP is the Model Context Protocol, an open standard that lets an AI assistant call tools on a server. A connector is one such server URL that you add to ChatGPT, Claude, Codex or Gemini. This one gives the assistant 18 read-only tools that look up public data and name the source of every answer.

Is it free?

Yes. A free key allows 100 tool calls a day with no card. Pro is $19 a month for 5,000 tool calls a day. A keyless trial endpoint allows 10 calls a day per network.

Does it give medical or legal advice?

No. EMS results are education and reference text from published protocol books, not medical direction. Judge and court results are public records for information only, not legal advice. Check primary sources before you rely on a result.

Can it change anything on my accounts?

No. All 18 tools are read-only. They look up public data and return it with its source.

Where does the data come from?

Protocol Guide for EMS protocols, JudgeFinder for judges and courts, CMS NPPES and openFDA for public health data, and Hugging Face for open-model sizing.
